# Prevision-app

Control de Previsión Total para Servicios Funerarios Huerta: una PWA de una sola página (`index.html`), sin build step. Tailwind CSS y Lucide Icons se cargan por CDN; el manifest y el Service Worker (`sw.js`) se inyectan/registran en línea para permitir la instalación como app.

## Skills

- **coreyhaines31/marketingskills** — Colección de skills de marketing para agentes de IA (CRO, copywriting, SEO, analítica, growth, ads, pricing, etc.). El skill base `product-marketing` sirve de referencia para el resto.
  - Instalación vía marketplace de plugins de Claude Code:
    ```
    /plugin marketplace add coreyhaines31/marketingskills
    /plugin install marketing-skills
    ```
  - Instalación vía CLI:
    ```
    npx skills add coreyhaines31/marketingskills
    ```
